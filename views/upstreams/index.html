帮助手册

整体模式 Provider ID

其他插件选择 multi_api_router 后，会按右侧从上到下的顺序尝试已启用路由的聊天兼容 API。任一 API 返回响应后立即停止，不再调用后续 API。

启用路由 Provider

关闭后，整体模式和各个指定上游 Provider 都不会参与调用。适合临时停用整套路由，而不是逐条关闭 API。

回退主模型

开启后，只有上游发生真实调用且全部失败，才回退 AstrBot 主模型一次。健康检查直接跳过的上游不算真实失败。

“回退 Provider ID”留空时使用 AstrBot 默认主模型；填写 deepseek/deepseek-flash 这类 ID 时，会固定回退到该 Provider。

跳过已确认的配置错误

开启后，自动路由会跳过近期检测确认的认证、路径或额度错误（HTTP 401/402/403/404，其中 402 表示额度不足或欠费）并写日志。超时、连接失败和临时服务异常不会冻结接口，指定单个上游也仍可调用。

异常重试与等待间隔

“每个上游异常重试次数”不含首次调用，设为 0 即关闭重试；“异常重试间隔”支持小数秒，只控制本轮请求等待多久后重试，不冻结后续请求。仅超时、连接错误、HTTP 408 和 5xx 原地重试，参数、认证和限流错误直接结束该上游尝试。

“单次接口超时”控制每次上游调用，“最多尝试的上游数量”控制自动路由候选数量。调用、重试等待和回退全部计入路由总时限，超时后即停止，因此不保证用完配置的重试次数。

路由超时与拖拽排序

“路由超时限制”覆盖排队、逐个尝试和主模型回退，达到总时限后立即停止。按住左侧三点拖动整行；同类 API 中越靠上越先调用。

单个 API 配置

新增 API 默认勾选“启用路由”。取消后只退出整体自动路由，配置完整的聊天、图转文和多模态 API 仍可被其他插件直接指定使用。启用路由但缺少必填项时无法保存。

获取模型列表

填写 API Base 和 API Key 后点击“获取模型”，插件会从服务器调用 OpenAI 兼容的 /models 接口。获取成功后可在模型 ID 输入框中选择，也可继续手动填写。

模型能被列出不代表当前 Key 一定有调用权限；部分中转站也可能不提供模型列表接口。

API 类型

聊天、图转文和多模态使用 Chat Completions，可参与当前整体路由并注册直连 Provider。生图、Embedding、Rerank、STT、TTS、ASR 按各自协议检测，不会被错误发送到聊天接口。

生图和 TTS 只做手动检测，检测会真实生成最小结果，可能产生少量费用；自动每小时检测不会调用这两类 API。

工具调用

勾选后，该 API 才能接收 function calling 请求。例如天气查询带工具时会跳过“无工具”的 API；全部不支持时会明确报错，不会假装执行工具。

思考能力

默认关闭，即请求体携带 enable_thinking=false。Qwen3 等支持该参数的模型可手动开启；普通模型不支持时应保持关闭。

指定某个上游

其他插件的模型选择器会直接显示上游名称和模型，不展示内部路由前缀。选中后只走该 API，不自动切换，也不回退主模型。

每行左侧的 #编号 是固定槽位号（例如 #12 对应 multi_api_router:upstream_12），拖拽排序或删除其他条目都不会改变它；其他插件引用时用的就是这个编号。已删除的编号会退役，不会被新条目复用。

保存与撤销

任何配置变化都会弹出底部提示。点击“保存并生效”立即热重载；点击“取消并撤销”会恢复上一步操作。点击页面空白处也会执行同样的单步撤销。
