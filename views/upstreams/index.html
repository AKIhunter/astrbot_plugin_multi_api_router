帮助手册

整体模式 Provider ID

其他插件选择 multi_api_router 后，会按右侧从上到下的顺序自动选择上游。例如 #1 请求失败后尝试 #2，直到达到最大尝试次数。

启用路由 Provider

关闭后，整体模式和各个指定上游 Provider 都不会参与调用。适合临时停用整套路由，而不是逐条关闭 API。

回退主模型

开启后，只有上游发生真实调用且全部失败，才回退 AstrBot 主模型一次。健康检查直接跳过的上游不算真实失败。

“回退 Provider ID”留空时使用 AstrBot 默认主模型；填写 deepseek/deepseek-flash 这类 ID 时，会固定回退到该 Provider。

跳过不健康上游

开启后，最近健康检查明确失败的 API 会被临时跳过并写日志。例如 #1 返回 HTTP 402，下一次请求会直接从 #2 开始。

拖拽排序

按住每条 API 左侧的三点拖动整行。页面显示的 #1、#2、#3 会自动重排；保存后，上方 API 的调用级别更高。

单个 API 配置

展开一条路由可设置启用状态、名称、API Base、API Key 和模型 ID。新增 API 默认启用；如果必填项未填完整，保存时会明确指出缺少哪一项。

工具调用

勾选后，该 API 才能接收 function calling 请求。例如天气查询带工具时会跳过“无工具”的 API；全部不支持时会明确报错，不会假装执行工具。

思考能力

默认关闭，即请求体携带 enable_thinking=false。Qwen3 等支持该参数的模型可手动开启；普通模型不支持时应保持关闭。

指定某个上游

展开项里会显示专属 Provider ID，例如 multi_api_router:upstream_5。其他插件选择它时只走该 API，不自动切换，也不回退主模型。

常见搭配示例

后台摘要：#1 放免费文本模型，#2 放稳定付费模型，并选择整体模式；视觉插件：直接选择视觉 API 的专属 Provider；工具任务：只给真正支持工具调用的 API 勾选工具能力。

保存与撤销

任何配置变化都会弹出底部提示。点击“保存并生效”立即热重载；点击“取消并撤销”会恢复上一步操作。点击页面空白处也会执行同样的单步撤销。
